# Skills

Personal Claude Code skills, installable on any device (macOS, Windows, Linux) as a plugin.

```
/plugin marketplace add 1mposer/Skills
/plugin install 1mposer-skills@1mposer
```

Pull updates with `/plugin marketplace update 1mposer`. To add a skill, put a `<name>/SKILL.md` folder at the repo root and list it in `.claude-plugin/plugin.json` → `skills`.
